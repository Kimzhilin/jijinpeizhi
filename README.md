# 偏股基金平衡配置 · 调仓助手

一个**纯静态、可部署到 GitHub Pages** 的网页工具，把你之前确认的「稳健偏防御型偏股基金配置 + 现金机动（随市场浮动，当前 20%）+ 跌补涨减再平衡」逻辑做成可日常使用的记账 / 调仓助手。策略比例 / 现金 / 阈值 / 基金列表由「理财财市场自适应引擎」每日自动更新，你打开页面即是最新版。

无需服务器、无需数据库、无需密钥。数据存在浏览器本地（localStorage），净值来自东方财富公开接口。

---

## 功能

1. **设定可投金额** → 自动按当前策略比例生成 5 只基金的部署金额 + 现金机动（目标比例随市场浮动，当前约 20%）。
2. **记录交易** → 你按建议买入 / 卖出后，在「记录交易」里登记（基金 / 方向 / 金额 / 净值），工具实时更新持仓、市值、盈亏。
3. **实时行情** → 打开页面或点「刷新行情」即拉取最新官方净值与当日涨跌，并重算你的盈亏。
4. **调仓建议引擎** → 按既定纪律自动给出可执行的买卖建议：
   - 季度再平衡：任一只偏离目标 **±阈值（见「策略面板」，当前 ±8%）** 调回；
   - 成长止盈：科创50 / 创业板累计盈利达档位（见策略面板，当前 **+25% / +45%**）分批减仓入现金；**已执行的分档点「✓ 我已执行」即消失**，盈利回吐到线下方自动复位可再触发；
   - 低吸加仓：自近 3 月高点回撤，按档位（见策略面板，当前宽基 -10%/-18%/-28%、成长 -12%/-22%/-32%）分档从现金加仓；**已执行的分档同样点「✓ 我已执行」即消失**，价格回升突破该档自动复位；
   - 现金纪律：现金目标随市场浮动于 **10%–30%**（当前 20%），不做死板固定；单日波动 ≤3% 不主动操作。
5. **交易记录** → 完整留痕，可随时清空重来。

**风险偏好（底仓姿态）**：策略面板顶部有「我的风险偏好」下拉（稳健 / 平衡 / 进取）。它在引擎每日自动算出的基线之上做底仓微调——稳健会再多留现金、压低成长仓位；进取则相反。这是本地设置，不影响自动调仓节奏，也不写进策略文件，你随时可改。

### 导入已有持仓（清仓前已买的部分）

直接走「② 记录交易 → 买入」即可，**无需特殊模式**：

1. 基金选对应的（如创业板 `110026` / 南方中证A500 `022434`）；
2. 日期填你**实际买入的那天**；
3. 金额填当时**投入的本金**；
4. 净值填你**实际买入时的净值**，或直接用 App 里的「持仓成本价」（用成本价，盈亏会和平台显示一致）。

工具的「现金」是**派生值 = 总投入 − 已投成本基准**：你每登一笔，现金自动扣减，建满后自然停在 20% 附近，全程不用手调。已有持仓的盈亏会按你的真实成本基准正确计算。

**金额怎么填、现金在哪看、后期怎么加钱：**
- **「设定初投金额」填 100% 总金额**：直接填你准备投入这个计划的全部本金（例如打算投 100 万就填 `1000000`），**不用自己先扣 20%**——工具自动预留现金机动（当前约 20%，随策略在 10%–30% 间浮动）、剩下约 80% 部署 5 只基金。
- **现金在哪看**：除了顶部总览，② 持仓/行情 区底部有「现金机动状态」面板 + 持仓表合计行，实时显示当前现金、目标现金、偏差、占比与状态。
- **后期追加投资**：用「① 配置」里的「追加」按钮，填**新增**金额（不是累计）。新钱进现金池，目标配置同步上调，已登记持仓与盈亏全部保留；你再按建议逐步部署。若误改「设定初投金额」为不同数字，弹出确认框，不会静默覆盖。

## 部署到 GitHub Pages

**方式一：用 Git 推上去（推荐，一次配置后全自动）**
1. 在 github.com 新建一个**公开**仓库（例如 `fund-allocator`）。
2. 本地进入本目录，执行：
   ```bash
   git init
   git add .
   git commit -m "init 理财财调仓助手"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/fund-allocator.git
   git push -u origin main
   ```
3. 仓库 → **Settings → Pages → Build and deployment → Source** 选 `Deploy from a branch`，Branch 选 `main`，目录 `/ (root)`，保存。
4. 约 1–2 分钟后访问 `https://kimzhilin.github.io/jijinpeizhi/` 即可（本仓库已部署于此地址）。

**方式二：网页直接上传**
把本目录全部文件（含 `.github/`、`strategy.js`、`sw.js`、`.nojekyll`）上传到仓库根目录并提交，再按方式一步骤 3 开 Pages。

> 已内置 `.nojekyll`，GitHub 不会用 Jekyll 处理，确保 `strategy.js` / `sw.js` 正常以静态文件服务。

**全自动维护（部署后你基本不用管）**
- **策略每日自动更新**：仓库内置 GitHub Actions（`.github/workflows/update-strategy.yml`）每个工作日 16:30（北京时间，收盘后）跑引擎、重算 `strategy.js` 并提交；你下次打开页面即是最新比例 / 现金 / 阈值。
- **离线也能看**：页面打开时会把当天的策略与净值缓存进浏览器（localStorage），并注册了 Service Worker 缓存网页外壳（`sw.js`）。断网后再次打开，看到的是**最近一次联网时的数据**，顶部状态栏会标明「离线 · 显示缓存净值（最近 X月X日）」，不会白屏。净值只在联网刷新时更新，离线仅供「参考」用。
- **实时估值说明**：联接基金净值每个交易日收盘后才更新一次，工具显示的是**最新官方净值 + 当日涨跌 + 近3月高点**，满足「每日市场情况 + 离线参考」；免费公开接口**无可靠盘中实时估算**（原 `fundgz` 估值接口已失效），故不提供分时跳动，绝不编数字。

> 本地试用：直接双击 `index.html` 也能跑（localStorage 在本地可用）；但 Service Worker 仅在 https（GitHub Pages）下生效，离线打开能力需在部署后体验。

## 数据说明与限制（重要）

- 数据来源：东方财富公开接口 `pingzhongdata`。联接基金**净值每个交易日收盘后才更新一次**，所以工具显示的是**最新官方净值**，而非分时跳动。这满足「每日更新 / 跟进盈亏」的需求；若要分钟级盘中估值，免费公开接口目前不可用（原 `fundgz` 估值接口已失效）。
- 接口偶发不可用或限流时，「刷新行情」可能取不到数据，此时可在「记录交易」里**手动填写净值**，不影响记账与建议。
- 纯静态站点本身没有后台：**页面关闭期间净值不会自动更新**（净值需打开页面或点「刷新行情」才拉取，交易时段 9:30–15:00 页面自动每 5 分钟刷新一次）。但**策略文件已做到无人值守自动维护**：仓库内置 GitHub Actions（`.github/workflows/update-strategy.yml`）每个工作日 16:30（北京时间，收盘后）自动跑引擎、重新生成 `strategy.js` 并提交；你下次打开页面即套用最新比例 / 现金 / 阈值，无需手动干预。
- 所有计算在本地浏览器完成，你的金额、持仓、交易记录**只存在你自己的浏览器里**，不会上传任何服务器。
